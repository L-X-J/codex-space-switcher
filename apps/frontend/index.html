Create Account

新增账号

先选择账号类型，再填写对应信息。保存前都会先做一次必要校验，避免把无效账号写进路由配置。

官方账号配置

访问 chatgpt.com/api/auth/session ，复制完整 JSON 后粘贴到这里。系统会测试 accessToken 是否可用，再保存为本地快照。

只会保存路由所需字段，不会额外保存 sessionToken。

第三方账号配置

保存前会先请求你填写的 /models。若中转站未实现该接口，可再次点击保存以跳过本次校验。

保存前会先做一次连通性测试。

Restart Required

需要重启 Codex

配置已写入 ~/.codex/config.toml，需要重启 Codex Desktop 才能生效。

重启前，当前 Codex 仍会继续使用旧配置。

Confirm Switch

切换前确认

切换到该账号会先改写 ~/.codex/config.toml，随后需要重启 Codex Desktop 才能生效。是否继续？

只有你确认继续后，系统才会真正写入 ~/.codex/config.toml。
